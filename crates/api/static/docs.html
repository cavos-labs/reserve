Reserve

A Stellar sponsor so a user can exist and transact by paying reserves and fees in a held token. Classic G… accounts only.

There is no signup. Call the API without a header. A key is a bigger rate-limit bucket, not a permission. Testnet and mainnet are the same endpoints under /testnet and /mainnet.

Not the OpenZeppelin Relayer

Stellar spends XLM as a fee and locks XLM as a reserve. Those are different costs. The OpenZeppelin Relayer is infrastructure you run to submit transactions. In sponsored mode it lets a user pay fees in a token. You bring the operations or the XDR — including Soroban. Creating an account and sponsoring its reserves are operations you can put in the envelope if you already know how; they are not what that product sells.

Reserve is a hosted sponsor. The user pays reserves and fees in the same token, in the same transaction. A G… address can be created with a zero XLM minimum (CAP-33) and fee-bumped (CAP-15). An address that holds only USDC can exist and transact. It never holds XLM.

  • OZ Relayer: you operate it. Arbitrary operations, including Soroban. Fees in tokens if you configure it. A source account is assumed.
  • Reserve: hosted. Four operations. Classic accounts only. Activate from a claimable balance. No arbitrary XDR.

Need Soroban or a general submit pipeline? Use a relayer. Need a user who does not hold XLM to exist? This.

What else it is not

  • Not custodial. Reserve never holds a user key and never adds itself as a signer.
  • Not Soroban. Contract ids (C…) are refused.
  • Not a dashboard. Signing a challenge again returns the same key. Nothing is stored.
